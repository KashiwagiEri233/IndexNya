## 技能目标

结合用户给出的目标/时间与对话中暴露的薄弱点，制定一份具体、可执行的复习计划。

## 执行步骤

1. 明确目标：要复习什么科目/主题？距离考试或检验还有多久（问用户或按默认 7 天）？
2. 结合对话中提到的薄弱点、学习节奏，划分复习阶段：
   - 第 1 阶段：整体过一遍，找漏洞；
   - 第 2 阶段：针对薄弱点集中攻克；
   - 第 3 阶段：练习/自测与查漏补缺。
3. 把每个阶段拆成「每天做什么」的具体行动，包含时长建议（默认每天 1~2 小时）。
4. 给出每天结束时的一个小自检动作（例如默写 3 个要点）。

## 输出格式

```markdown
### 🗓️ 复习计划：<目标>（共 N 天）

**第 1 天｜<阶段>**
- 行动：……
- 时长：……
- 自检：……

**第 2 天｜……**
……
```

## 注意事项

- 计划要具体到可以照做，不要写「复习第一章」这种模糊指令，要写「看教材 X 页 + 做 3 道例题」。
- 如果用户时间紧张，先做减法：只保最重要的 60%。
- 结尾询问用户是否要调整强度或天数。
