## 技能目标

把用户当前学习的主题或对话中的知识点，整理成一组「问答式记忆卡片」，帮助用户随时自测背诵。

## 执行步骤

1. 从用户请求或上文对话中提炼出 5~10 个核心知识点（概念、定义、公式、易错点均可）。
2. 每个知识点拆成一张卡片：
   - 正面：简短问题（如「什么是时间复杂度？」）
   - 背面：简洁准确的答案（1~3 句，可用公式或例子辅助）。
3. 卡片难度从易到难排列；给每张卡片标注所属知识点主题。

## 输出格式

用以下 Markdown 结构输出：

```markdown
### 📇 记忆卡片：<主题>

**卡片 1**
- 问：……
- 答：……

**卡片 2**
- 问：……
- 答：……
```

## 注意事项

- 答案要正确、精炼，不要照抄教材长段落。
- 如果用户说出「我要背 X」，优先围绕 X 生成卡片。
- 最后可提示用户：可以把卡片复制到自己的笔记软件中复习。
